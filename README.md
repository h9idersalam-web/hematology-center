# نظام متابعة مرضى الدم

تطبيق ويب يُثبَّت على الهاتف لمركز أمراض الدم: ملف المريض، والبروتوكول العلاجي، وجدول الجرعات،
والتحاليل، وموافقة الطبيب المختص على تعديلات الصيادلة، وقسم المزج الكيميائي.

## أين يوجد كل شيء

| المجلد | المحتوى |
|---|---|
| `web/` | واجهة التطبيق، وتُنشر تلقائياً على GitHub Pages |
| `supabase/` | ملفات قاعدة البيانات، تُشغَّل في Supabase › SQL Editor بالترتيب |
| `tests/` | اختبارات قاعدة البيانات والواجهة (للمطوّر) |

**بيانات المرضى لا تُحفظ في هذا المستودع أبداً.** كلها في Supabase، ومحميّة بسياسات أمان الصفوف.

## الإعداد

1. شغّل في Supabase الملفات `01_schema.sql` ثم `02_storage.sql` ثم `03_seed_protocols.sql` ثم `05_hardening.sql`.
2. ضع رابط المشروع والمفتاح العام (anon أو publishable) في `web/js/config.js`.
   لا تضع المفتاح السري (service_role أو secret) في أي ملف هنا.
3. فعّل النشر: Settings › Pages › Source: **GitHub Actions**.
4. افتح رابط التطبيق، وأنشئ حسابك، ثم شغّل `04_make_admin.sql` لتصبح مدير النظام.

```bash
node tests/ui-test.cjs ./shots           # اختبار الواجهة بالمتصفح
```
